# 📚 MERN Stack E-Commerce Bookstore

A modern, full-stack e-commerce application developed to manage books, shopping carts, and user authentication seamlessly. This project showcases a clean architecture separating frontend UI and backend server logistics.

## 🚀 Features
* **User Authentication:** Safe registration and login interface.
* **Role-Based Views:** Optimized sections for searching and browsing books.
* **Shopping Cart System:** Interactive cart functionality allowing users to manage book items before checking out.
* **Database Management:** Fully dynamic data fetching from MongoDB Atlas.
* **Modern UI:** Clean, responsive, and easy-to-read Light Theme styling.

## 🛠️ Tech Stack
* **Frontend:** React.js, Vite, Custom CSS3
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas (Mongoose ODM)
* **Environment Security:** Dotenv configuration

## 📂 Project Structure
* `bookstore-client/` - Complete React frontend with specialized components, contexts, and routes.
* `server/` - Node/Express backend containing controllers, models, and API routes.
